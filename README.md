
# StudyMate AI 🧠

An AI-powered web app that helps students summarize lecture notes, extract key points, and draft professional academic emails — built to practice Technical Product Management and AI integration.

# 🧩 Features (MVP)
- Upload `.txt` or `.pdf` lecture notes
- AI-generated summary (TL;DR + key points + quiz)
- Context-aware email drafting (professor, course, purpose)
- History page with saved summaries
- Rating + feedback system
- Privacy-first: users can delete their data anytime

# 🧠 Tech Stack
- Frontend: Next.js + TailwindCSS
- Backend: Supabase (Postgres + Auth)
- AI: OpenAI GPT-4o-mini API
- Deployment: Vercel
